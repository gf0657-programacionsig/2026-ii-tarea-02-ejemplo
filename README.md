# Población y densidad de los cantones de Costa Rica en 2022

**Autor:** Manuel Vargas

Ejemplo de la [tarea 2](https://gf0657-programacionsig.github.io/2026-ii/tarea-02/) del curso GF-0657 Programación en SIG (II ciclo 2026), Escuela de Geografía, Universidad de Costa Rica. Es un cuaderno de análisis de datos con pandas y gráficos interactivos de plotly, a partir de las estimaciones de población y vivienda del INEC para 2022.

## Cuaderno de notas

- [tarea-02.ipynb](tarea-02.ipynb): el cuaderno, ejecutado, con sus salidas guardadas.
- [![Abrir en Google Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/gf0657-programacionsig/2026-ii-tarea-02-ejemplo/blob/main/tarea-02.ipynb) Abre el mismo archivo del repositorio en Colab.

**Los gráficos de plotly no se ven en el visor de GitHub**, porque no ejecuta JavaScript: al abrir el cuaderno en GitHub las celdas de los gráficos aparecen vacías. Para verlos, abra el cuaderno en Colab con el botón anterior y ejecute todas las celdas (menú *Entorno de ejecución > Ejecutar todas*). Como los datos se cargan desde una URL, el cuaderno se ejecuta en cualquier lugar.

## Datos

- [cantones-2022.csv](cantones-2022.csv): una fila por cantón (82), preparada a partir del archivo Excel del INEC. El cuaderno lo carga desde su dirección *Raw* en este repositorio.

## Fuente de los datos

Instituto Nacional de Estadística y Censos. (2023). *Resultados Estimación de Población y Vivienda 2022* [Conjunto de datos]. INEC. https://admin.inec.cr/sites/default/files/2023-11/reResultadosEstimacionPoblacionVivienda2022_3.xlsx
